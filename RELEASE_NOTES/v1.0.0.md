## Overview

**Version 1.0.0** is the first stable, production-ready release of the **PM System** — a full-stack Project Management and Timesheet Integrated Solution built for organisations to manage projects, tasks, team members, client billing, and timesheet approvals in a single unified platform.

This release establishes the complete core feature set across 13 functional requirement modules, covering the full workflow from project creation through task execution, time tracking, manager approvals, invoice generation, and client-facing reporting.

## Bugs Fixed in This Release

| Bug ID | Description | Root Cause | Fix |
|---|---|---|---|
| BUG-001 | Invoice status change duplicated records | Frontend was sending POST instead of PATCH on status update | Changed to PATCH `/api/invoices/:id/status` |
| BUG-002 | Invoice totals multiplied by 10x when toggling status | Duplicate invoice line items were being aggregated | Database cleanup + PATCH-only status endpoint |
| BUG-003 | Non-approved logs included in invoice | Time log query missing status filter | Added `status IN (L1_APPROVED, L2_APPROVED, LOCKED)` filter |
| BUG-004 | Tasks list showed project code not name | Frontend was referencing `project.code` field | Switched to include `project.name` from API response |
| BUG-005 | `</Head>` JSX tag causing build failure | Typo (`</Head>` instead of `</TableHead>`) | Corrected to `</TableHead>` |
| BUG-006 | MUI Grid `align="right"` TypeScript error | `align` prop removed in MUI v5 Grid | Replaced with `sx={{ textAlign: 'right' }}` |
| BUG-007 | CLIENT users could access internal employee panels | No role guards on sidebar nav items | Added `isAllowed(roles)` guards in DashboardLayout |
| BUG-008 | Recharts SVG hydration mismatch in Next.js | SSR rendered charts before client mounted | Added `isMounted` boolean guard before rendering Recharts |

## API Endpoints Added

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/client-portal/dashboard` | Client portal dashboard data |
| `GET` | `/api/invoices` | List all invoices |
| `POST` | `/api/invoices` | Generate new invoice |
| `GET` | `/api/invoices/:id` | Get invoice detail |
| `PATCH` | `/api/invoices/:id/status` | Update invoice status only |
| `DELETE` | `/api/invoices/:id` | Cancel/delete invoice |

## Known Limitations

- No native PDF generation (uses browser print dialog)
- No automated email on invoice dispatch
- No 2FA UI (backend model exists)
- No file attachments for tasks/timesheets
- No dark mode
- No multi-currency support
